Turn an Excel workbook into SQL,
and prove every number matches.

Drop in an .xlsx. cellproof translates every formula to SQL, runs it on DuckDB, and checks each result against the value Excel itself saved. Each formula cell is PASS, FAIL, or UNRESOLVED with the reason. It never guesses.

🔒 Runs entirely in your browser. Your workbook is never uploaded.

Findings

    1 · TranslateEvery formula becomes SQL with Excel's own rules: types, error codes, the order errors win.
    2 · VerifyEach cell is checked against the value Excel saved in the file. A free answer key.
    3 · ShipYou get a dbt project on DuckDB that runs exactly the SQL that was checked.
    Use it on your machine or in CI

    Same engine, plus --dbt to run dbt build. Free and MIT-licensed.

    pip install cellproof && cellproof convert book.xlsx
